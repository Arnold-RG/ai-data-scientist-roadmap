# Career notes (study, not recruiting advice as a promise)

Demand is real; the learning curve is real; burnout is real. Treat those as facts, not posters.

## Why people like the work

- Problems span science, software, and the business.
- The field moves; boredom is rare if you like learning.
- The same skills transfer across industries (with new domain vocabulary).

## Why people quit

- You will spend more time on missing keys than on elegant models.
- Stakeholders want certainty. Your job is calibrated uncertainty.
- The stack changes faster than any degree.

You do not need a specific degree. Computer science, math, physics, economics, and self-taught paths all appear in the wild. You do need a **portfolio of decisions**, not a list of courses. This repository is designed to produce those artifacts (the ten projects).

## How to use this repo on a résumé

Pick three projects (EDA, experiment or forecast, and either NLP or the capstone). For each, write four lines: question, data (synthetic is fine if you say so), method, result including a limitation. Link the GitHub folder.

## Next roles

If you finish this map and love production more than questions, look at ML engineering. If you love LLM products, the AI engineer roadmap. If you love SQL and stakeholders, data analyst. Adjacent is not failure.
