# Skills map

Aligned to the ten stages and to what hiring managers actually probe.

| Skill | Stage | How this repo trains it |
| --- | --- | --- |
| Linear algebra, calculus | 01 | Lessons + `exercises/stage_01_math.py` |
| Probability, inference, experiments | 02 | A/B project + stats exercises |
| Causal thinking, time series | 03 | Econometrics lessons + forecast project |
| Python, DSA, SQL | 04 | Coding exercises |
| Wrangling, EDA, visualization | 05 | Retail EDA project |
| Classical ML | 06 | Houses + segments |
| Deep learning & representation | 07 | Sentiment + shapes + attention exercise |
| Deployment, CI, monitoring | 08 | Model API + GitHub Actions |
| LLM systems (RAG, agents) | 09 | RAG-lite |
| AI-assisted engineering | 10 | Protocol + capstone |
| Communication | all | Every project writes JSON or markdown a PM could read |
| Domain knowledge | capstone | You invent the product story for churn |

Programming languages: **Python** is mandatory here; **SQL** is mandatory; R is useful in some teams and omitted so the repo stays one stack.

Soft skills: translating a metric into a decision, saying “the experiment is underpowered,” refusing a leaked feature. Practice those in the interview case studies.

Staying current: read one paper after Stage 07 (Attention is all you need) and one after Stage 09 (the original RAG paper). Do not collect bookmarks instead of finishing projects.
