# Stage 04 — Coding

Data scientists who cannot code are stuck in other people’s notebooks. This stage is **Python**, **data structures and algorithms at interview depth**, and **SQL**.

You are not training for a systems olympiad. You are training to:

- wrangle a table without melting the machine,
- write a query a data engineer will respect,
- survive a whiteboard that asks for frequencies, windows, and joins.
