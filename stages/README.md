# Stages

Ten stages, in the same order as [roadmap.sh/ai-data-scientist](https://roadmap.sh/ai-data-scientist).

| Stage | Folder | One-sentence point |
| --- | --- | --- |
| 1 | [01-mathematics](01-mathematics) | Models are linear algebra moved by calculus. |
| 2 | [02-statistics](02-statistics) | Every number from data needs an uncertainty story. |
| 3 | [03-econometrics](03-econometrics) | Prediction is not causation; identification is the gap. |
| 4 | [04-coding](04-coding) | Python, SQL, and enough algorithms to not get stuck. |
| 5 | [05-eda](05-eda) | Most of the job is understanding the table in front of you. |
| 6 | [06-machine-learning](06-machine-learning) | Supervised, unsupervised, and ensembles with honest metrics. |
| 7 | [07-deep-learning](07-deep-learning) | From dense layers to CNNs, sequence models, and transformers. |
| 8 | [08-mlops](08-mlops) | A model that cannot be deployed and watched is a demo. |
| 9 | [09-ai-engineering](09-ai-engineering) | Prompts, RAG, agents, and fine-tuning as system design. |
| 10 | [10-vibe-coding](10-vibe-coding) | AI coding tools used with tests and judgment. |

How to move: lesson → `exercises/` → quiz → project. See [HOW_TO_STUDY.md](../HOW_TO_STUDY.md).
