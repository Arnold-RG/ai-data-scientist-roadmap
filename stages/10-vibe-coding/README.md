# Stage 10 — AI-assisted coding

The official roadmap calls this **vibe coding**: AI coding assistants and AI app builders.

Used well, they are a force multiplier for Stages 4–9. Used poorly, they generate plausible code that fails the test you should have written.

This stage is professional practice, not a personality.

## Lesson

[AI coding assistants](01-ai-coding-assistants.md)

## Practice

```bash
python quizzes/run_quiz.py --stage 10
python quizzes/run_quiz.py --exam
python projects/10-capstone/train.py
```

The capstone is where you combine EDA, a model, and a written decision. You may use an assistant to draft code. You may not skip the report.
